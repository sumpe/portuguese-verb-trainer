# Treino de Verbos Portugueses 🍪

A single-page European Portuguese verb conjugation trainer.

- Quiz yourself on 10, 20 or 30 forms across nine tenses (indicative, conditional, subjunctive incl. future subjunctive)
- Verb groups: regular (-ar/-er/-ir), essential, frequent and complementary irregulars
- Optional *vós* forms and a synthetic-forms-only mode
- Conjugation tables comparing European Portuguese with Spanish, with irregular stems/endings highlighted

## Usage

No build step: open `index.html` in a browser.
